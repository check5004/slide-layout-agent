# スライド作成AIワークフロー

**手元の文章と画像から、あとで編集できる PowerPoint を作ります。**

渡すものは、調査済みの文章、またはスライドごとに分けた文章。画像も添付できます。Codex が構成と配置を考え、Python が `.pptx` に仕上げます。

## まず完成例を見る

- **[62型のカタログを見る](catalog/index.html)**（clone後にブラウザで開くと検索・配色切替ができます）
- **[62型の差込サンプルPPTX](catalog/samples/catalog-warm.pptx?raw=true)** · [別配色](catalog/samples/catalog-cool.pptx?raw=true)
- **[構成から生成までの架空3枚](examples/catalog-story/story.pptx?raw=true)** · [従来8型の見本](examples/demo.pptx?raw=true)

サンプルの文章・数値・画像は、動作確認用の架空のものです。

## 最短の使い方

### 1. Codex にこう頼む

このリポジトリを取得し、そのフォルダを Codex で開きます。別 PC で始める場合も [clone とセットアップの手順](docs/usage.md) は同じです。

> AGENTS.md と .agents/skills/slide-plan/SKILL.md を読んでください。
>
> work/ に置く文章と画像から、編集できる PowerPoint を作りたいです。
>
> 必要な環境をこのプロジェクト内に準備し、まず構成案を見せてください。
>
> 原文にない事実は追加せず、省略や不明点は知らせてください。

### 2. 環境を準備する

生成に必要なのは **Python 3.11 以降とライブラリ**です。初回はプロジェクト専用の仮想環境に入れます。手動で進める場合は [セットアップ手順](docs/usage.md) を参照してください。

AI に構成を考えてもらうには **Codex** が必要です。このプロジェクト用の API キーや追加の有料 API は不要です。

PowerPoint 本体は生成には不要ですが、出力を開いて見た目を確認・手直しするときに使います。自動の画像書き出し・計測は Windows ＋ PowerPoint 向けです。

62型は上流テンプレートの游ゴシック・游明朝とコンパクトな文字サイズを使います。従来8型は Meiryo。追加フォントの導入は生成の必須条件ではありません。別 OS では代替フォントによって改行や見た目が変わることがあります。

### 3. 文章と画像を置く

`work/` フォルダを作り、文章を `input.txt`、画像があれば `photo.png` などの名前で保存します。スライドごとの文章は、Markdown の `## 見出し` で区切れます。

`work/` は Git 管理対象外です。個別の資料を公開用サンプルの `examples/` に入れないでください。

### 4. 構成案を確認する

Codex に資料とカタログを読み込んでもらい、ページの順序・テンプレート・省略箇所を確認します。「この説明は残して」「ここは比較にして」と伝えて直せます。各型の必須欄を原文だけで埋められない場合は、別の型や構成を選びます。

構成案は `work/plan.json`、確認用のファイルは `work/review.md` に保存します。

### 5. PowerPoint を生成する

構成案がよければ、Codex に「この構成で生成して」と頼みます。原文参照や文字量などを検証して、`work/result.pptx` を出力します。

文字が収まらない場合は、ページを分けるか構成を直します。読めない大きさまで自動縮小することはありません。

### 6. PowerPoint で手直しする

出力を開き、全ページを確認します。**文字・図形・表・登録されたグラフは編集可能**です。写真や添付画像の内部は、そのまま画像として扱います。

PowerPoint 上の手直しを構成案へ戻す機能はありません。手直し版は別名で保存してください。

## いま使える範囲

日本語・16:9 の**実体PPTXテンプレート62型**と、従来のPython配置8型に対応しています。62型は2配色・124枚の描画見本から選べます。従来の文章＋画像も同じ構成案に混在できます。

**62型は保存済みのPPTXを開き、名前付きの入力欄へ差し込む方式です。** 文字量・表やグラフの項目数・数値の関係を型ごとに検証します。任意の企業テンプレートを自動登録する機能や、出力PPTXの手修正を取り込む機能はありません。

AI の判断は Codex が担当し、Python はフォント・配色・余白・配置を決められたルールで描画します。題材の調査や事実の追加は行いません。意味や留保が正しく残っているか、最終的には人間が確認します。

原文・数値の機械的な一致と、意味の確認は別です。数値の引用に条件や留保があり、表示文で確認できない場合は警告します。検証結果の`ok`は意味の保持を承認する値ではありません。
