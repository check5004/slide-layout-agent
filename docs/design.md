# 仕組みと制約

[README に戻る](../README.md) · [操作手順](usage.md) · [検証記録](verification.md)

## Codex と Python の役割

**Codex は、原文をどう分け、どう見せるかを考えます。** スキルを読み、原文への参照付きで構成案 `plan.json` を作ります。

**Python は、指定された内容を決められた配置で描画します。** `python-pptx` を使い、フォント・配色・余白・配置を管理します。CLI 自体に LLM/API 呼び出しはありません。

対象は調査済みの文章と手元の画像です。題材の調査や事実の補完は行いません。このプロジェクト用の API キーや追加の有料 API は不要ですが、構成を考えるには Codex の利用環境が必要です。

## 現行方式と開発中の方式

現行版の配置は Python のコードで定義しています。AI は8種類の `layout_id` と内容を選びます。既存のテンプレート PPTX を読み込んで差し込む実装はありません。

同梱の `examples/demo.pptx` は生成結果のサンプルです。テンプレートとして CLI に読み込ませるファイルではありません。

テンプレート PPTX とプレビュー、入力欄の容量を見て AI が選択し、Python が差し込む方式への拡張は開発中です。現行の操作手順は、完成前の機能を前提にしていません。

## 入力から出力まで

1. **入力を固定**：`source.json` に原文・ID・画像情報を保存。
2. **構成を考える**：Codex が原文参照付きの `plan.json` を作成。
3. **人間が確認**：順序、表現、省略、不明点を確認。
4. **検証して描画**：Python が内容と制約を検証し、PPTX を生成。
5. **見た目を確認**：PowerPoint などで全ページを確認して手直し。

AI に任意の Python や無制限の座標を渡させる設計にはしていません。入力や画像内の命令は資料の内容として扱い、それを根拠にコード実行、ファイル取得、外部送信は行いません。

## 原文をどう追跡するか

構成案と原文を SHA-256 で結び付けます。各テキストや数値には、ソース ID と原文からの正確な引用を付けます。出典はスライドのノートにも残します。

追加された数値、抜けた数値、原文の改変、不正な引用を検査します。未使用の原文、部分的な省略、言い換えも追跡し、確認箇所を知らせます。明示的な省略を含む生成には、確認後の `--accept-omissions` が必要です。

意味・因果・留保の一致を完全に自動判定することはできません。数字が一致しても、単位や対象を取り違えていないかは人間が確認します。

## 編集できる範囲

| 要素 | PowerPoint での編集 |
|---|---|
| 文字 | 文章、フォント、位置などを編集可能。 |
| 図形・矢印 | 個別の図形として編集可能。 |
| 表 | 表のまま、セルの内容などを編集可能。 |
| 対応する縦棒グラフ | PowerPoint のグラフと埋込 Excel データとして編集可能。 |
| 写真・添付画像 | 移動・拡大縮小・トリミングは可能。内部の文字や物体は個別編集できない。 |

スライド全体を1枚の画像にした PPTX は生成しません。

**手直しした PPTX から構成案への逆取り込みは未対応です。** 手直し版は別名で保存してください。JSON から再生成すると、PowerPoint 側だけの修正は引き継がれません。

## 見た目のルール

日本語・16:9、標準フォントは Meiryo。配色は濃紺・青緑・白系です。テーマを変える場合は、同じ JSON を検証と生成の両方で指定します。

| 項目 | 標準 | 許容範囲 |
|---|---|---|
| `title_pt`：タイトル | 32 pt | 28–36 pt |
| `body_pt`：本文 | 24 pt | 22–28 pt |
| `table_pt`：表 | 20 pt | 18–22 pt |
| `footnote_pt`：出典 | 12 pt | 11–14 pt |
| `lead_mode`：短い要旨 | `false` | `true` のとき18 ptの要旨を許可。 |

`font_family` でフォントを指定できます。色は `background`、`foreground`、`accent`、`secondary`、`muted`、`surface`、`surface_alt` に6桁の16進数で指定します。[Theme の定義](../slide_agent/models.py) が詳細な仕様です。

文字量は保守的に見積もります。収まらなければ分割または停止し、自動縮小や切り捨てで隠しません。画像は、全体を見せる `fit` か、枠いっぱいに中央を切り抜く `crop` を選びます。

## 現在の制約

- 8種類の配置：表紙、箇条書き、文章＋画像、比較、手順、表、縦棒グラフ、締め。
- 最大100スライド。テキスト入力2 MB、JSON 5 MBまで。
- 画像はPNG/JPEGのみ。1枚20 MB・4,000万画素まで。
- 表は2～3列、データ6行／ページまで。
- グラフは非負の値による集合縦棒のみ。最大6分類・2系列。
- 自動分割は箇条書き項目と表の行に対応。他の長文は構成案を修正する。
- Web UI、テンプレート PPTX 読み込み、PPTX から構成案への逆取り込みは未対応。
- 他 OS・代替フォント・LibreOffice での完全互換性は未検証。

各配置の入力内容と制限は [JSON の仕様](contract.md) にまとめています。

## 検証の範囲

`validate` は、型・原文ハッシュ・引用・数値・文字量・画像・パスの範囲を確認します。

`render` はさらに、PPTX 内部の XML、配置範囲、文字サイズ、自動縮小の不使用、編集可能な要素を検査します。結果は `*.validation.json` に出力します。

これらは、実フォントや Office の描画差を含めた見た目の保証ではありません。全ページを実際に描画して確認する工程が必要です。[検証記録](verification.md) には、テストと PowerPoint での描画結果を分けて記載しています。

## 資料の保存と公開

個別の入力・構成案・出力は、Git 管理対象外の `work/` または `out/` に保存します。公開するのはコード・汎用文書・架空サンプルだけです。個人資料や認証情報をコミットしないでください。
